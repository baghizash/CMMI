===============================================
  CMMI SYSTEM - CARA JALANKAN (Windows)
===============================================

PERTAMA KALI (Setup 1x saja):
=============================
1. Pastikan MySQL running di Laragon
2. Double-click: first-time-setup.bat
3. Tunggu selesai (~5-10 menit)

SETIAP KALI JALANKAN:
=====================
Buka 2 terminal / command prompt berbeda:

Terminal 1 - Backend:
  Double-click: start-backend.bat
  
Terminal 2 - Frontend:
  Double-click: start-frontend.bat

AKSES:
======
Frontend:    http://localhost:3000
Backend API: http://localhost:8000

LOGIN:
======
Username: admin
Password: admin123

JIKA ADA ERROR:
===============
Frontend force close?
  1. Double-click: clean-install.bat
  2. Tunggu selesai
  3. Double-click: start-frontend.bat

Backend error?
  Check console untuk error message
  Pastikan MySQL sudah running

Port sudah dipakai?
  Edit batch file, ganti port (mis: 8001, 3001)
